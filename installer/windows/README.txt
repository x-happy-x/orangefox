OrangeFox для Xiaomi 17 Pro Max (popsicle), Android 16

Полностью распакуйте ZIP в доступную для записи папку на компьютере.
Сохраните все подпапки и имена файлов. ADB и fastboot уже включены в пакет.

Требования: Windows PowerShell 5.1, установленный USB-драйвер ADB/fastboot,
уже разблокированный загрузчик и только один подключённый телефон.
Отключите остальные Android-устройства и эмуляторы.

Можно начать из обычного Android, recovery или bootloader fastboot.
В обычном Android заранее включите отладку по USB и авторизуйте компьютер.
Используйте bootloader fastboot; userspace fastbootd не подходит.

flash.cmd — установить OrangeFox.
restore-twrp.cmd — вернуть включённый в пакет проверенный TWRP.
Возврат TWRP меняет только recovery; отдельно установленный KernelSU сохраняется.

Установщик проверяет SHA256 файлов, модель, serial, разблокировку загрузчика,
текущий слот и размер раздела. Записывается только recovery текущего слота
(recovery_a или recovery_b). После подтверждённой записи телефон перезагрузится
в recovery. Результат останется в окне до нажатия клавиши.

Если при старте доступен root ADB, копия текущего recovery сохраняется
в подпапку backups рядом с установщиком. При старте из fastboot для возврата
доступен проверенный TWRP из пакета. При ошибке прочитайте сообщение в окне;
автоматического повторения записи нет.

flash.cmd не устанавливает root. Magisk и KernelSU выбираются отдельно
в меню OrangeFox. KernelSU 3.3.1 LKM является экспериментальным вариантом;
выполненные проверки установки и загрузки описаны в DEVICE-TEST.md.

Версия прошивки для проверки и выполненные виды проверки записаны
в metadata.json. Флаг загрузки recovery не означает проверку установки root.
Подробный отчёт о проверках и известных проблемах PIN/RPC: DEVICE-TEST.md.
