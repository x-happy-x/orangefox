# ANDROID-5: экран и пакет popsicle-2026-10-20

Кандидат `20261020T080341Z` собран отдельно от опубликованного тега
`popsicle-2026-10-19`. Новый релиз пока не опубликован.
Изменения и проверки прежней версии сохранены в
[ANDROID-3](ANDROID-3-device-test.md) и [публикации 19 октября](PUBLICATION.md).

Целевые изменения:

- Высота статусбара — 108 единиц темы вместо 72; maintainer — `x-happy-x`.
- Оранжевый интерфейс должен правильно отображаться на физическом экране.
  Правильный цвет PNG-скриншота сам по себе не подтверждает цвет панели.
- В релиз загружаются только `recovery.img` и
  `OrangeFox-popsicle-2026-10-20.zip` с Windows-установщиком.
- В установочном ZIP нет Markdown-документов, образа возврата или сценария
  возврата другой recovery. Проверки модели, разблокировки, текущего слота,
  размера раздела и целостности остаются обязательными.

Проверено для кандидата:

- `recovery.img`: 104857600 байт (100 MiB), SHA256
  `c4c8d630deefd4fee94d3c9d76f9373b35e89f6ecda3c1656ef34686107a4a98`.
- `OrangeFox-popsicle-2026-10-20.zip`: 90993119 байт, SHA256
  `892c9eca186cf8c317ce7901b3f09ef5efb361379ede7df393525fabc2b7679b`.
- Структура IMG, равенство вложенного IMG и все SHA256/CRC установочного ZIP
  прошли проверку. В ZIP ровно 12 файлов; документов Markdown, образа и
  сценария возврата другой recovery, README и справочных файлов нет.
- Совпали 27 файлов устройства, 4 root-компонента и 2 crypto-helper.
  Maintainer `x-happy-x` подтверждён в двух упакованных местах: свойствах и
  бинарнике recovery. В фактической команде компиляции задан `OF_STATUS_H=108`.
- 43 offline-проверки установщика прошли в Windows PowerShell 5.1 и PowerShell 7.

Код цветового вывода не менялся: статическая проверка DRM/RGBX не выявила
ошибки соответствия форматов. Физические цвета, статусбар и загрузка после
полного выключения нового IMG пока не проверены на телефоне. Цвет PNG не
подтверждает цвет панели, а результаты предыдущего IMG не заменяют эту
проверку. Установка root остаётся отдельным действием; прошивка recovery не
удаляет уже установленный KernelSU из `init_boot`.

Соответствующие исходники, resolved manifest и патчи этой сборки сохраняются в
Git под `port/releases/popsicle-2026-10-20/`; уведомления авторов и лицензии — в
[THIRD-PARTY](THIRD-PARTY.md) и `docs/licenses/`. Они доступны вместе с Git-тегом,
отдельный пользовательский source-архив релиза не требуется. GitHub также
автоматически предоставляет архивы исходников тега.

Перед публикацией остаётся аппаратная проверка нового IMG. Публикация и
синхронизация зеркала пока не выполнялись.
