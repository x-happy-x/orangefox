# ANDROID-5: экран и пакет popsicle-2026-10-20

Сборка `20261020T082441Z` для релиза `popsicle-2026-10-20`.
Изменения и проверки прежней версии сохранены в
[ANDROID-3](ANDROID-3-device-test.md) и [публикации 19 октября](PUBLICATION.md).

Целевые изменения:

- Высота статусбара — 108 единиц темы вместо 72; maintainer — `x-happy-x`.
- SPR bypass учитывает настройку панели; оранжевый цвет проверен пользователем.
- В релиз загружаются только `recovery.img` и
  `OrangeFox-popsicle-2026-10-20.zip` с Windows-установщиком.
- В установочном ZIP нет Markdown-документов, образа возврата или сценария
  возврата другой recovery. Проверки модели, разблокировки, текущего слота,
  размера раздела и целостности остаются обязательными.

Проверено для сборки:

- `recovery.img`: 104857600 байт (100 MiB), SHA256
  `efad86390600a1510665c23201a33ca0af3324fa270dbe4992de25b91fd21801`.
- `OrangeFox-popsicle-2026-10-20.zip`: 90993490 байт, SHA256
  `cd687c30a2fc9c3184c478a6b2d891d550ec48ed546af674556ac64b7cd9cf04`.
- Итоговый ZIP: CRC всех 14 записей, 12 файлов, размеры и все 11 хешей из
  metadata совпали; вложенный IMG равен отдельному образу, служебные файлы
  имеют атрибут Hidden, ссылки на внешние runtime-файлы отсутствуют.
- Структура IMG и сравнения файлов прошли проверку: 27 файлов устройства,
  4 root-компонента, 2 crypto-helper, 2 файла identity и библиотека дисплея.
- IMG прошит schema 2 установщиком в текущий `recovery_a`; чтение раздела
  после записи совпало с IMG. `boot_a`, `init_boot_a`, `init_boot_b` и
  `recovery_b` сохранили исходные хеши.
- Recovery загрузилась, `twrp.decrypt.done=true`, `vendor.secure_element`
  работает, `twrp.adsp.ready=true`. Свойство maintainer — `x-happy-x`.
- Реально используется DRM; в журнале есть
  `setting up SDE_SPR_INIT_CFG_V2, bypass 1`. Упакованная `libminuitwrp.so`
  совпала с собранной, SHA256
  `2201176a72f346e1691d84f5ffdaf855f64342794756a339521a2fe54c033ed4`.
- Maintainer `x-happy-x` подтверждён в двух упакованных местах: свойствах и
  бинарнике recovery. В фактической команде компиляции задан `OF_STATUS_H=108`.
- 43 offline-проверки установщика прошли в Windows PowerShell 5.1 и PowerShell 7.

Добавлена поддержка свойства SPR bypass и обнуление SPR-структур по
закреплённому TWRP-Test; RGBX/DRM формат пикселей сохранён. Host-проверки
реальных V1/V2 builders и отрицательные контроли прошли. Предыдущий кандидат
`082045` с устаревшей упакованной библиотекой отклонён до прошивки; причины и
проверки описаны в [display-notes](../port/display-notes.md).

Пользователь подтвердил физический экран: «Цвет оранжевый, панель подходит».
В About отображается `x-happy-x`; фонарик проверен пользователем.
Запуск после прошивки через Fastboot проверен; отдельного полного выключения не было.
Установка root остаётся отдельным действием; прошивка recovery не удаляет
уже установленный KernelSU из `init_boot`.

Окончательный ZIP перепакован с отметкой проверенной загрузки recovery;
установка root этой сборкой повторно не проверялась. Состав — 12 файлов без
пользовательских README/MD и возвратного образа или сценария; обязательные
`NOTICE.txt` и `source.properties` сохраняются.

Соответствующие исходники, resolved manifest и патчи окончательной сборки
зафиксированы в Git под `port/releases/popsicle-2026-10-20/`;
уведомления авторов и лицензии — в
[THIRD-PARTY](THIRD-PARTY.md) и `docs/licenses/`. Они доступны вместе с Git-тегом,
отдельный пользовательский source-архив релиза не требуется. GitHub также
автоматически предоставляет архивы исходников тега.
