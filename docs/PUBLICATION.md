## Проверенная конфигурация

Xiaomi 17 Pro Max (`popsicle`), Android 16, HyperOS
`OS3.0.319.0.WPBCNXM`, security patch `2026-08-01`, штатное ядро
`6.12.23-android16-5-g75e9b1c7ae7c-abogki463945075-4k`.

Подтверждены загрузка, сенсор, основное хранилище с существующим PIN после
автоматического запуска Secure Element, UI, nano save/exit, фонарик и возврат
в Android. KernelSU 3.3.1 LKM загружен; официальный Manager показал **Working**.
Включение/выключение модуля проверено на собственной пустой тестовой записи.
Magisk 30.7 проверен только на файлах образов.

Это результат одного устройства и указанной firmware/kernel. Ошибка
расшифровки профиля `999` остаётся ограничением. OTA, MTP, sideload, OTG,
fastbootd, установка сторонних ZIP/модулей и все сценарии выключения питания
не проверены. Полная хронология: [ANDROID-3](ANDROID-3-device-test.md).

## Что публикуется как исходники

Git хранит сценарии среды/сборки, закреплённые manifest и project SHA,
device overlay, проверяемые исходные изменения, рецепты root addons,
readiness helper, Windows-установщик и результаты проверок в документации.
Полный AOSP checkout, WSL-диск/экспорт, скачанные upstream-бинарники, личные
бэкапы разделов и содержимое пользовательских файлов в Git не включаются.
Готовые IMG/ZIP публикуются артефактами релиза.

Архив `popsicle-2026-10-19-sources.zip` дополняет снимок финального публикуемого
тега точным manifest всех 404 проектов и шестью применёнными патчами итоговой сборки.
Это указатель на соответствующие исходники: upstream URL и revision каждого
проекта указаны в `build-manifest.xml`; локальные изменения — в патчах и рецептах.
Для официальных бинарников Magisk/KernelSU закреплены исходные ревизии и ссылки
на релизы в [releases.json](../port/root-addons/releases.json).
Исходное дерево устройства, включая prebuilts, и Android/OrangeFox/TWRP-компоненты
доступны по закреплённым ревизиям upstream. Их лицензии и уведомления авторов
сохраняются; архив рецептов не заменяет полные upstream-репозитории.

Исходные ревизии и адаптация: [sources.env](../port/sources.env),
[local-manifest.xml](../port/local-manifest.xml),
[locked-projects.json](../port/locked-projects.json),
[VALIDATION](../port/VALIDATION.md).
Файлы изменений проверяются по закреплённым upstream Git blobs;
полный разрешённый manifest сохраняется рядом с каждой сборкой.
Закрепление исходников не является обещанием побайтно одинаковых результатов
при разных времени и среде сборки.

Текст релиза: [release-popsicle-2026-10-19.md](release-popsicle-2026-10-19.md).
Локальная история подготовки WSL сохранена отдельно:
[LOCAL-ENVIRONMENT](LOCAL-ENVIRONMENT.md).
